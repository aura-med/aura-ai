Arquitectura de Papéis (RBAC) — PhysioElite
Dois ambientes completamente separados. O atleta só acede à Athlete App (wellness self-reporting). O staff acede à Plataforma Principal com visibilidade definida pelo papel. Os dados fluem unidireccionalmente: atleta → API segura (Supabase EU, MFA, Row Level Security) → plataforma staff.
Athlete App — Acesso Exclusivo do Atleta
Check-in manhã (Hooper + TQR + HRV + peso) RPE pós-sessão Histórico pessoal (14 dias)
O atleta NÃO vê dados de outros atletas · NÃO acede à plataforma staff · NÃO vê o score de risco preditivo
