Cada variável entra com o seu valor bruto — por exemplo ACWR = 1.47, HRV = 53ms, Fadiga = 8/10. Unidades heterogéneas que o passo 2 vai converter numa escala comum.
Passo 2 — Normalização contra limiares publicados na literatura. Transforma unidades heterogéneas (ms, km/h, escala 1–10) em valores entre 0 e 1. Zero = dentro do normal. Um = no limite máximo de risco documentado. Este passo ancora o modelo à ciência publicada.

Passo 3 — Score parcial por variável (0 a 1). Cada variável tem agora um valor comparável. Zero = sem risco. Um = risco máximo documentado. Este é o passo que torna o modelo interpretável — o clínico pode ver qual factor está mais alto.

Porquê este passo é a chave da interpretabilidade
Com um modelo de ML neural, o fisioterapeuta recebe 82% e não sabe mais nada.

Com scores parciais visíveis, o fisioterapeuta vê que:

• O ACWR (0.90) é o factor dominante
• O historial (0.55) contribui menos
• A intervenção prioritária é reduzir carga hoje, não trabalhar o historial
Isto é interpretabilidade clínica real — saber qual factor actuar primeiro, hoje, neste atleta.
Passo 4 — Soma ponderada. Cada score parcial é multiplicado pelo seu peso. Os pesos somam 1.0 e são definidos com base na literatura (Fase 1). Na Fase 2, após ~30 eventos de lesão registados na FPF, são recalibrados por regressão logística com dados reais.

Na Fase 2, após dados reais da FPF, o ACWR pode passar a pesar 0.32 e o historial 0.18. O mecanismo não muda — só os valores dos pesos.
Fórmula aplicada — P. Oliveira
Score = Σ (score_parcial_i × peso_i)

= 0.90 × 0.25 = 0.225
+ 0.82 × 0.20 = 0.164
+ 0.80 × 0.15 = 0.120
+ 0.85 × 0.08 = 0.068 ← TQR
+ 0.75 × 0.07 = 0.053 ← Sono
+ 0.55 × 0.10 = 0.055
+ 0.70 × 0.10 = 0.070
+ 0.50 × 0.05 = 0.025

= 0.780 → normalizado → 82%
Passo 5 — Camada de confiança. Antes de apresentar o score, o modelo avalia a qualidade dos dados que o geraram. Um score calculado com dados incompletos é sempre apresentado com aviso explícito — nunca silenciosamente. Esta camada resolve o problema específico do contexto de selecção nacional.

Esta camada é uma inovação de produto, não de algoritmo. Nenhum modelo académico ou comercial existente comunica explicitamente ao clínico a qualidade dos dados que geraram o score. É o que distingue um instrumento clínico responsável de uma caixa preta com um número.
Passo 6 — Output final para o clínico. O score chega com três camadas simultâneas: o número, a decomposição por variável, e o índice de confiança. Os cinco passos anteriores correm em segundo plano — o clínico vê apenas o resultado, mas pode sempre inspeccioná-lo.

O que o clínico vê vs. não vê
Vê: score, decomposição por variável, confiança, recomendação de acção
Não vê: a matemática interna, os limiares, os pesos — abstraídos no output
Diferença face ao ML convencional
Um modelo neural devolve 82% sem mais informação.

A PhysioElite devolve 82% e acrescenta:
"O factor dominante é o ACWR — carga desta semana excede 47% a carga crónica. Se reduzires o volume hoje, o score desce para ~65% amanhã."

Isso é o que torna o score accionável.
